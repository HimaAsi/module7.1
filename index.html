7.1 FORMATTING & STYLES

Global Design Changes

Ensuring consistency in fonts, spacing, and alignment.

⚠️ Manual Formatting
You start writing and manually change this text to Times New Roman, make it blue, and align it left.
Then for the next part, you accidentally select Comic Sans, center alignment, and huge line spacing!
By page 3, you are using red Courier New. The document looks completely unprofessional.
✅ Using "Styles"
"Body Text" Style Rules
➔
Apply to All
Instead of formatting word by word, you create a rule.
You tell the Word Processor: "Make all Body Text look like this."
When you update the style, the entire document instantly obeys.
